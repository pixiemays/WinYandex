# История изменений (Changelog)

Все заметные изменения в проекте WinYandex документируются в этом файле.

---

## [0.9.1] — 2026-10-23

### 🌊 Моя волна
* **Обновление иконки Моей волны**: Заменена стандартная иконка воспроизведения («Play») возле заголовка «Моя волна» и пресета по умолчанию на иконку аудиоволны (`Streaming Waves`). Это устранило путаницу пользователей, воспринимавших значок как индикатор текущего проигрывания.

### 🔊 Управление громкостью
* **Расширенный слайдер громкости**: Увеличена ширина ползунка громкости (до 160 px в нижней панели управления и до 150 px в боковой шторке полноэкранного плеера) для более комфортного и точного позиционирования.
* **Интерактивный ввод процентов**: Добавлено интерактивное текстовое поле процентов (например, `65%`):
  * При клике активируется поле ввода, позволяющее ввести точное значение от `0` до `100%`.
  * Поддерживается подтверждение клавишей `Enter` и отмена по `Esc`.
* **Регулировка колесом мыши**: Добавлена возможность плавно изменять уровень громкости с шагом 2% при прокрутке колеса мыши над областью регулятора громкости.
* **Исправление иконки динамика**: Исправлено отображение глифа динамика на низких уровнях громкости (< 33%). Теперь отображается динамик с одной волной звука вместо пустого/беззвучного рупора.
* **Исправление обрезки кнопок**: Устранены паразитные внутренние отступы (`Padding="0"`) на кнопках выключения звука (Mute), эквалайзера и текстов песен, из-за которых края иконок обрезались.

### 🔐 Авторизация и безопасность
* **Безопасная авторизация через внешний браузер**: Добавлена возможность входа через системный браузер по умолчанию (Chrome, Edge, Firefox и др.) по защищённому протоколу OAuth Яндекс ID.
* **Умный перехват токена из буфера обмена**: Приложение автоматически слушает буфер обмена во время процесса авторизации: как только пользователь копирует итоговый адрес перенаправления, WinYandex мгновенно распознаёт токен и завершает авторизацию без ручной вставки.
* **Бейдж доверия SSL для WebView2**: Встроенное окно авторизации дополнено защитным баннером с зелёным замком и верификацией официального домена `passport.yandex.ru`.

## [0.9.0] — 2026-10-23

### 🚀 Первый публичный релиз
* Полноценный нативный клиент Яндекс Музыки на стеке WinUI 3 + Windows App SDK + C# .NET 8.
* Fluent Design с материалом Mica, поддержкой тёмной и светлой тем Windows.
* Поддержка персонального потока «Моя волна» с фильтрами настроения и занятий.
* Воспроизведение треков, плейлистов, альбомов и артистов.
* Встроенный 10-полосный эквалайзер с пресетами.
* Синхронизированные тексты песен в реальном времени.
* Локальный дисковый LRU-кэш для мгновенного повторного воспроизведения без интернета.
* Бесшовное предзагрузочное воспроизведение треков (Gapless audio preload).
* Функция «FckCensor» для автоматической подмены зацензуренных версий треков на оригинальные.
* Интеграция с Windows: SMTC (клавиши мультимедиа), системный трей, миниатюра панели задач, тост-уведомления.
* Интеграция со статусом Discord Rich Presence.
* Двуязычный интерфейс (Русский / Английский) с автоопределением языка системы.
