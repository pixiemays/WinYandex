# YMusic 🎵

> **Современный нативный клиент Яндекс Музыки для Windows 10/11 на WinUI 3 и .NET 8.**

[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D4?logo=windows)](https://github.com)
[![Framework](https://img.shields.io/badge/.NET-8.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/)
[![UI](https://img.shields.io/badge/UI-WinUI%203%20%2F%20Windows%20App%20SDK-0078D4)](https://github.com/microsoft/WindowsAppSDK)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**YMusic** — это быстрый, легковесный и эстетичный десктопный плеер для Яндекс Музыки, разработанный с нуля на нативном стеке Windows (WinUI 3 + Windows App SDK + C# .NET 8) вместо тяжеловесного Electron.

---

## ✨ Особенности и возможности

* 🎨 **Нативный Fluent Design** — визуальный стиль Windows 11 с эффектами материалов Mica / Acrylic, плавной анимацией и поддержкой темной/светлой темы.
* 🔤 **Выверенная типографика** — ультрачёткий экранный шрифт **Inter** по умолчанию с возможностью переключения в настройках на фирменный **Yandex Sans** или системный **Segoe UI Variable**.
* ⚡ **Дисковый аудио-кэш (LRU)** — воспроизведенные треки сохраняются в локальный кэш (`%LocalAppData%/YMusic/Cache`) для мгновенного повторного воспроизведения (0 мс) без повторного расхода трафика.
* 🎵 **Бесшовный переход (Gapless Playback)** — предзагрузка аудиопотока и текстов следующего трека при достижении 80% текущей песни для исключения задержек и буферизации.
* 🎤 **Синхронизированные тексты песен (Караоке)** — выдвижная шторка Now Playing с синхронным ведением текста строка-в-строку.
* 🎚️ **10-полосный аудио эквалайзер** — прецизионная настройка звука от 31 Гц до 16 кГц с готовыми пресетами (Rock, Pop, Bass Boost, Vocal, Acoustic и др.).
* 🌊 **Моя волна (My Wave)** — бесконечный умный поток рекомендаций с быстрым переключением активности (*Работа, Отдых, Дорога, Спорт*) и настроения (*Спокойное, Бодрое, Радостное, Грустное*).
* 🛡️ **FckCensor** — умная разблокировка: автоматическое предпочтение оригинальных версий треков без цензуры вместо заглушенных правообладателями вариантов.
* 💬 **Discord Rich Presence** — детальное отображение текущего трека, имени артиста, обложки альбома и статуса воспроизведения в вашем профиле Discord.
* 🔔 **Глубокая интеграция с Windows**:
  * **SMTC (System Media Transport Controls)** — нативное системное всплывающее окно громкости и управление с клавиатуры/гарнитуры.
  * **Taskbar Thumbnail Toolbar** — кнопки воспроизведения прямо в превью панели задач Windows при наведении курсора.
  * **Системный трей** — аккуратная иконка в трее с контекстным меню и опцией сворачивания вместо закрытия.
  * **Toast-уведомления** — всплывающие системные баннеры Windows при смене трека.
* 🌍 **Двуязычный интерфейс** — моментальное переключение между русским и английским языками прямо в приложении без перезапуска.

## 📥 Установка и запуск

Вы можете выбрать любой удобный формат:

### 1. Установщик Setup.exe (Рекомендуется)
Скачайте готовый `YMusic-Setup-x64.exe` из раздела [Releases](https://github.com) и запустите. Приложение установится в систему, создаст ярлык в меню «Пуск» и на рабочем столе.

### 2. Портативная версия (ZIP)
Скачайте архив `YMusic-win-x64-portable.zip`, распакуйте в любую удобную папку и запускайте `YMusic.WinUI.exe`. Приложение полностью автономно и не требует предустановленного .NET Runtime.

### 3. Пакет MSIX Bundle
Для установки как родное приложение Windows 10/11 дважды кликните по `YMusic.WinUI_x64.msixbundle`.

## 🛠️ Сборка из исходников

### Требования
* Windows 10 (сборка 17763+) или Windows 11
* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
* Visual Studio 2022 (с компонентами *Разработка приложений для Windows*) или VS Code с C# Dev Kit

### Сборка и запуск в режиме разработки:
```powershell
# Клонирование репозитория
git clone https://github.com/pixiemays/WinYandex.git
cd WinYandex

# Запуск приложения
dotnet run --project src/YMusic.WinUI/YMusic.WinUI.csproj
```

### Сборка релиза и дистрибутивов:
```powershell
# Сборка автономного Release-билда и Portable ZIP архива
powershell -ExecutionPolicy Bypass -File scripts/package_release.ps1
```
*Все готовые релизные файлы сохраняются в папку `dist/`.*

## 🧱 Архитектура и технологии

* **Платформа:** Windows App SDK (WinUI 3) + .NET 8
* **Архитектурный паттерн:** MVVM (CommunityToolkit.Mvvm)
* **Аудио-движок:** Windows MediaFoundation / NAudio
* **Шрифты:** Inter Variable Display & Yandex Sans Text
* **Интеграции:** DiscordRichPresence, Windows.System.Media.SystemMediaTransportControls, Microsoft.Windows.AppNotifications
